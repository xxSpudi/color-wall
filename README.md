# Цветная стена

Пинг-понг об стену из цветных секций. Мяч меняет цвет после каждого отскока от стены, отбей его в секцию того же цвета.

- Тот же цвет: +1 очко. Не тот цвет: очко не засчитывается.
- Пропустил мяч: минус сердце, сердец 3.
- 15 очков: победа.
- Этапы: Разминка (3 цвета), Перемешка (с 5 очков, 4 цвета, после верного попадания секции меняются местами), Два мяча (с 10 очков).

Управление: зажми левую кнопку мыши и веди ракетку.

## Запуск
Windows: `Build/Color Wall.exe`.

## Файлы
- `Build/` — билд для Windows (Unity 6000.4).
- `ColorWall_presentation.pptx` — презентация игры.
